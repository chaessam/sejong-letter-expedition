# 세종의 글자 원정대

세종의 글자 원정대와 함께 한글 마을을 탐험하는 3D 학습 게임입니다.
세종대왕과 글자를 배우고, 배를 타고 이웃 마을로 떠나 흩어진 초대장을 찾아 모두를 잔치에 초대해요.

![세종의 글자 원정대 게임 썸네일](thumbnail.png)

## 바로 해 보기

<https://sejong-letter-expedition.pages.dev/>

## 조작 방법

| 동작 | 키보드·마우스 | 휴대폰·태블릿 |
| --- | --- | --- |
| 이동 | `W` `A` `S` `D` 또는 방향키 | 왼쪽 아래 원형 조이스틱 |
| 이야기하기·사용하기 | 사람이나 물건 가까이에서 `E` | 화면의 이야기·사용 버튼 |
| 점프 | `Space` | 오른쪽의 점프 버튼 |
| 확대·축소 | 마우스 휠 | - |

- 휴대폰과 태블릿에서는 가로 화면으로 즐겨요.
- 원정 일지에서 미션을 읽고, 지도와 목표 표시를 따라가요.
- 미션을 마치지 않아도 연못에서 낚시를 하고 물고기 도감을 채울 수 있어요.

## 내 컴퓨터에서 열기

글꼴, 음악, 3D 라이브러리(Three.js)가 모두 `index.html` 한 파일에 들어 있어서 따로 설치하거나 빌드할 것이 없습니다.
저장소를 내려받은 뒤 `index.html`을 Chrome 또는 Edge에서 열면 됩니다.

3D 화면이 열리지 않으면 브라우저의 하드웨어 가속을 켜고 다시 열어 주세요.
